# 🧪 Vitamin AI: Intelligence-Driven Health Cloud

Vitamin AI is a world-class, premium health-tech SaaS ecosystem designed to optimize biological vitality through high-fidelity AI clinical scans, real-time biomarker synchronization, and precision nutrition mapping.

## 🚀 End-to-End Capabilities

### 1. Command Center Dashboard
*   **Vitality Index**: Real-time biological optimization score.
*   **Ecosystem Pulse**: Dynamic health metrics and interactive streak tracking.
*   **Predictive Risk Charts**: Longitudinal health projections based on current nutrient protocols.

### 2. Clinical Scan Station (AI Assessment)
*   **Symptom Mapping**: 15+ clinical indicators including Jaundice, Fatigue, and Neurological markers.
*   **Lifestyle Baseline**: Integration of diet, sleep, regional UV trends, and habit-based factors.
*   **Precision Perception**: High-confidence AI inference that correlates data with global clinical standards.

### 3. Medical Report Dossier
*   **High-Fidelity PDF Exports**: Professional-grade, print-optimized health report engine.
*   **Clinical Breakthroughs**: Detailed reasoning paths for identified deficiencies (Vitamin D, B12, Iron, etc.).
*   **Nutrient Profile Analysis**: Interactive radar charts for visualizing nutrient balance.

### 4. AI Nutritionist Assistant
*   **Contextual Chat**: High-fidelity AI assistant with clinical awareness and selectable persona modes.
*   **Deep Memory**: Remembers your health journey for personalized guidance and protocol adherence.

### 5. Advanced Biomarker Sync
*   **Clinical Logging**: Direct synchronization of blood test results (B12 pg/mL, Iron μg/dL, Vit D ng/mL).
*   **System Calibration**: Biomarkers automatically retrain the AI recommendation engine.

## 🛠️ Technology Stack

*   **Core**: React 18, Vite, TypeScript
*   **Intelligence**: Gemini AI Integration (Precision Clinical Inference)
*   **Interactions**: Framer Motion (Glassmorphism & Micro-animations)
*   **Styling**: Tailwind CSS (Tailored "Intelligent Dark" theme)
*   **Icons**: Lucide React
*   **Charts**: Recharts (Medical Data Viz)
*   **Authentication**: Clerk (Identity Management & GDPR compliance)

## 🏗️ Getting Started

1. **Clone & Install**:
   ```bash
   git clone https://github.com/Abhi-sys511/plant-disease-detection-web-app.git
   cd vitamin-deficiency-main
   npm install
   ```

2. **Configure Environment**:
   Create a `.env` file with your Gemini and Clerk credentials:
   ```env
   VITE_GEMINI_API_KEY=your_key
   VITE_CLERK_PUBLISHABLE_KEY=your_key
   ```

3. **Run Dev Environment**:
   ```bash
   npm run dev
   ```
